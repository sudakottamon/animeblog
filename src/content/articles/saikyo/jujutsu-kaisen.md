呪術廻戦の最強議論は、**「五条悟か、両面宿儺か」**という国民投票級の争点を抱えています。
当議会の議決を先に言うと——**基準によって答えが変わります**。だから2部に分けました。

**証拠採用範囲**
- アニメ基準: TVアニメ第2期「渋谷事変」＋劇場版0まで（第3期は放送完了後に改訂します）
- 原作基準: 原作完結まで（折りたたみ内に隔離）

査定の物差しは[議事規則](/rules/)の通り。初見・タイマン・相性込みの総合力です。

## アニメ基準TOP10（渋谷事変まで）

| 順位 | キャラ | 一言判決 |
|---|---|---|
| 1位 | 五条悟 | 描写が「最強」の設定に追いついている稀有な例 |
| 2位 | 両面宿儺 | 指15本未満で漏瑚を遊びで処理した |
| 3位 | 乙骨憂太 | 劇場版0の時点で特級。リカちゃん込みの火力は規格外 |
| 4位 | 夏油傑（渋谷の「あれ」含む） | 呪霊操術の理論値が高すぎる |
| 5位 | 漏瑚 | 宿儺に「誇っていい」と言わせた火力 |
| 6位 | 真人 | 無為転変は当たれば即死。成長速度も脅威 |
| 7位 | 七海建人 | 準1級の壁を実力で越えている描写多数 |
| 8位 | 伏黒甚爾 | 天与呪縛の完成形。五条に「勝ちかけた」唯一の男 |
| 9位 | 東堂葵 | 不義遊戯のIQと物理性能の両立 |
| 10位 | 虎杖悠仁 | 素の身体性能なら既にトップ層 |

### 主文（TOP3の判決理由）

**1位・五条悟。** 渋谷事変までのアニメ範囲で、五条は「無下限呪術の理屈」
「領域展開の格」「特級呪霊3体＋1を同時に処理する描写」まで揃っています。
最強設定のキャラは大抵描写が追いつかずに株を下げるものですが、
五条は逆で、描写が設定を補強し続けた。文句なしの主文です。

**2位・宿儺は「未完成でこれ」という恐怖。** 渋谷時点の宿儺は本来の力の半分以下。
それで漏瑚（単体戦力なら作中最上位の特級）を片手間に燃やしています。
完全体なら——という審理は原作基準パートで。

**3位・乙骨は「例外中の例外」。** 劇場版0のラストの解放描写は、
夏油に「五条家に迫る」と言わせた設定の実演でした。渋谷時点では海外にいるため
描写が凍結されており、この順位は劇場版0の証拠のみで議決しています。

### 争点

8位の伏黒甚爾を「五条に勝ちかけたのだからもっと上では」とする意見は
当議会でも審理しました。棄却した理由は、勝ちかけた相手が**覚醒前**の五条であること。
覚醒後に完敗している以上、上位陣との比較では描写不足です。

## 原作基準の最終議決（原作完結までのネタバレ）

**最終議決TOP5**

1. **両面宿儺（完全体）** — 指20本＋伏黒の術式込みの宿儺は、五条戦・最終決戦を通して「一人で物語の敵側全部」を務め切った。描写量・質ともに文句なしの主文
2. **五条悟** — 宿儺に敗れはしたが、審理すべきはその内容。魔虚羅の適応がなければ、という条件付きの敗北であり、純粋なタイマン性能の評価は落ちない
3. **乙骨憂太** — 終盤の連戦での万能ぶり（模倣術式）は、五条・宿儺に次ぐ第3席として異論の余地が少ない
4. **虎杖悠仁（最終盤）** — 御廚子を継承し、宿儺の魂に干渉する打撃。最終決戦の実質的な決定打
5. **鹿紫雲一** — 一撃の火力だけなら宿儺に「楽しかった」と言わせた側

アニメ基準からの最大の変動は**「五条1位→宿儺1位」の逆転**です。
これは五条が弱かったのではなく、宿儺の証拠（描写）が終盤に一気に積み上がった結果。
第5条の通り、議決は証拠が増えれば改訂されます。
